# Noiré Barber Shop – hemsida

Statisk one-page-sajt för Noiré Barber Shop, Köpmansgatan 2B, Halmstad.
Byggd av FQS Branding AB. Hostas på Vercel (ingen build behövs – filerna serveras som de är).

- `index.html` – hela sidan
- `assets/img/` – svartvita bilder
- `assets/fonts/` – Cinzel, Manrope, Cormorant Garamond (självhostade, OFL)
- `og-image.jpg` – förhandsbild när länken delas

Obs: sidan har `noindex` under förhandsvisningen. Ta bort raden `<meta name="robots" ...>` när sajten går live.
